# Order drafts

Support staff start an order on the phone and often cannot finish it in the same call. They want the unfinished orders kept as drafts and listed under the order list, so the next person on the call can see them, and they want to delete a draft once it is no longer needed.

Acceptance criteria:

1. A Drafts section below the order list shows every draft with its customer name, its total and when it was last changed.
2. Each draft has a Delete button; deleting removes the draft from the section without reloading the order list.
3. While the drafts load, the section shows a loading line; with no drafts it shows an empty line; when loading fails it shows an error line.
